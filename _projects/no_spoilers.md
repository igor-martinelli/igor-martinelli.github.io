### Overview

**No Spoilers** is a top-down, rogue-lite action game developed as part of the flagship **Game Programming Laboratory** course at **ETH Zurich**. 

Set in a decaying refrigerator after the owner leaves on vacation and the power goes out, players control fresh food items fighting their way through decaying maps, swarms of hostile enemies, and challenging bosses to find safety.

---

### Key Technical Features

* **Custom Game Architecture**: Built using Unity and C# with custom player controller mechanics, state machines, and modular item systems.
* **Procedural & Dynamic Gameplay**: Features fruit and vegetable power-ups that modify weaponry (swords and guns) in real time to adapt to diverse enemy waves.
* **Team Collaboration**: Developed collaboratively using agile software engineering principles, version control workflows, and rapid prototyping cycles.
